# Свой Telegram-бот у каждого пользователя

Вход в сервис идёт через Telegram OpenID Connect по Client ID и Client Secret одного бота, заданного в `.env`. Оповещения же каждый пользователь отправляет через собственное Подключение Telegram: своего бота, чей токен он вводит в UI. Боты для входа и для оповещений в коде никак не связаны. Так пользователи не делят между собой `getUpdates` и поиск чатов, а управление ботом не становится общей точкой отказа, которую может сломать любой пользователь. Плата за это — каждому пользователю нужно создать бота у @BotFather.

## Consequences

- `bot_id` уникален по всему сервису: один бот у двух пользователей перехватывал бы их обновления друг у друга.
- Каналы оповещения уникальны по `telegram_chat_id` в пределах бота, а значит, и в пределах пользователя.
