# AGENTS.md

Healthchecker: FastAPI + SQLite (backend) и SvelteKit SSR (frontend), запуск через Docker Compose.

## Источники правды

- **Термины** — `GLOSSARY.md`. Читать перед тем, как называть сущность в коде, API, UI или коммите; новый термин сначала фиксируется там.
- **Планы** — `docs/plans/`. Читать перед началом работы над этапом.
- **Архитектурные решения** — `docs/adr/`. Читать перед изменением архитектуры, описанной ниже.

## Архитектурные инварианты

- Браузер общается только с SvelteKit. FastAPI доступен лишь во внутренней сети Docker (`expose`, без `ports`), поэтому CORS отсутствует намеренно. Все обращения к API идут из серверного кода SvelteKit (`+page.server.ts`, `+server.ts`).
- Frontend на SvelteKit 3: переменные окружения объявляются в `frontend/src/env.ts` (`defineEnvVars`) и импортируются из `$app/env/private` / `$app/env/public`; `$env/*` устарел. Адрес API — приватная runtime-переменная `API_URL` (задаётся при запуске контейнера, не при сборке). Валидаторы `schema` выполняются и во время `vite build`, где runtime-переменных нет, поэтому пустое значение они должны пропускать.
- Backend работает строго одним процессом uvicorn, без `--workers`: фоновый исполнитель в `lifespan` должен существовать в единственном экземпляре.
- Схема БД меняется только миграциями Alembic; контейнер применяет их при старте (`alembic upgrade head`).
- `/api/health` отражает **Liveness** сервиса и не связан с проверками мониторов.

## Конвенции

- Коммиты — Conventional Commits на английском.
- Документация (README, планы, глоссарий, ADR) — на русском.
- Python 3.14, зависимости только через `uv`; `uv.lock` и `package-lock.json` коммитятся.
- Проверки перед коммитом — `make check`; остальные команды — `make help`.
